# 飞书应用配置指南

每个 Luckagent 机器人对应一个飞书「自建应用」。本文逐步走完从建应用到机器人回话的全流程。

> 💡 管理台内置了同款的「接入向导」（机器人管理 → 接入向导），把下面 7 步做成了页面向导，还带「测试连接」按钮验证凭证。喜欢图形界面可以直接用它，本文可作对照参考。见[管理台使用手册](admin-console.md#飞书接入向导)。

## 第一步：创建应用

1. 进入**飞书开放平台开发者控制台**：[open.feishu.cn/app](https://open.feishu.cn/app)
2. 点击**「创建自定义应用」**
3. 填写：
   - **名称**：机器人在飞书里显示的名字，如 "研发助手"
   - **描述**：如 "Luckagent 桥接机器人"
   - **图标**：选一个图标和颜色
4. 点击**创建**

## 第二步：记录凭证

1. 在应用主页，进入左侧**「凭证与基础信息」**
2. 复制 **App ID**（形如 `cli_xxxx`）和 **App Secret**
3. 填进 `bots.json` 该 bot 的 `feishuAppId` / `feishuAppSecret`（推荐，多 bot 模式），或单 bot 模式下填 `.env` 的 `FEISHU_APP_ID` / `FEISHU_APP_SECRET`

> 用管理台的话，这一步在向导「填写凭证」页粘贴即可，页面上的「测试连接」会实时调飞书接口验证凭证是否有效。

## 第三步：添加机器人能力

1. 左侧找到**「添加功能」**（功能模块下）
2. 找到**「机器人」**，点击**「+ 添加」**
3. 这会启用机器人能力，并在侧边栏增加「机器人」菜单

## 第四步：配置权限

1. 左侧进入**「权限管理」**（开发配置下）
2. 点击**「添加权限」**
3. 搜索并添加以下权限：

| 权限 | 用途 |
| --- | --- |
| `im:message` | 读取和发送私聊及群聊消息 |
| `im:message:readonly` | 读取私聊及群聊消息 |
| `im:resource` | 上传图片和文件（把产物发回聊天） |
| `im:chat:readonly` | 读取群信息（用于 2 人群检测） |

4. 点击**「添加」**确认

可选权限（按需）：

| 权限 | 用途 |
| --- | --- |
| `docx:document:readonly` | 读取飞书文档 |
| `wiki:wiki` | 读写知识库页面 |
| `docx:document` | 创建/编辑文档（知识库同步需要） |
| `drive:drive` | 访问云文档 |

> 另外，「引用回复 + @机器人」时注入**他人**被引消息上下文（[设计笔记 P](design-notes.md)）依赖应用的消息读取权限；租户未开通时会优雅降级，引用机器人自己的消息不受影响。

## 第五步：配置事件订阅

> ⚠️ **服务必须先启动**。「长连接」模式保存时飞书会实时验证 WebSocket 连接，服务不在线就保存不了。先 `luckagent start` 把桥接进程跑起来，再做这一步。桥接允许 `bots.json` 里先只填凭证（甚至空列表启动后经管理台补配），所以「先启动、后订阅」不冲突。

1. 左侧进入**「事件与回调」**
2. 点击**订阅方式**旁的编辑图标
3. 选择**「使用长连接接收事件」**（推荐——不需要公网回调地址）
4. 点击**保存** —— 飞书会验证 WebSocket 连接
5. 点击**「添加事件」**（连接验证通过后此按钮才可用）
6. 搜索 `im.message.receive`
7. 勾选**「接收消息」**（`im.message.receive_v1`）
8. 点击**确认**
9. 弹窗提示建议的权限时，点击**「添加」**

## 第六步：发布应用

1. 点击顶部的**「创建版本」**（或进入版本管理与发布）
2. 填写：
   - **版本号**：如 "1.0.0"
   - **更新说明**：如 "初始发布"
3. 默认能力应包含手机端和桌面端的「机器人」
4. 点击**保存**，然后在确认弹窗中点击**发布**
5. 如果组织允许小应用自动审批，会立即上线；否则等管理员审批

> 忘记发布是最常见的「机器人不回话」原因之一——应用凭证有效、长连接正常，但没发版对成员就是不可见/不可用的。

## 第七步：写入配置并测试

1. 确认 bot 已写入 `bots.json`（管理台向导最后一步「保存机器人」会代劳，含工作目录创建）
2. 重启桥接使配置生效：

```bash
luckagent restart
```

3. 打开飞书，搜索你的机器人名字
4. 发一条测试消息
5. 机器人应回复一张流式卡片，实时展示 agent 的响应过程

不回话？按[常见问题排查](troubleshooting.md#机器人不回话启动失败)一节逐项检查（`luckagent doctor --json` 一条命令能覆盖大半）。
