# seedance-video — 火山方舟 Seedance 生成视频

> 通过 `scripts/gen_video.py` 直连火山方舟 Ark 视频生成 API：提交异步任务 → 轮询 → 下载 mp4。
> 支持文生视频、图生视频（首帧图）、多模态参考、原生音频。默认模型 Seedance 2.5 `doubao-seedance-2-5-260628`（`SEEDANCE_MODEL` 可覆盖）。
> 需要火山方舟 key（`ARK_API_KEY`，与 image-gen 的 Seedream 共用一把），并在方舟控制台开通 Doubao-Seedance 模型。

---

## ⛔ 生成前强制关卡（先于一切，绝不跳过）

**视频生成慢（1~3 分钟）、贵（按分辨率×时长计费）、参数多。绝不允许"一听到生成就直接调脚本"。**
收到请求后先分诊：

### ① 信息不足 → 先问清楚，不生成
以下关键项缺失或含糊，**必须先问用户**（一次把该问的问完，别挤牙膏）：
- **画面内容**：要具体——主体、动作、场景、镜头运动、光线、风格。"生成个视频"这种一律先问要什么画面。
- **画幅比例**：`16:9`(横屏) / `9:16`(竖屏，抖音朋友圈) / `1:1`（2.5 另支持 `4:3` / `3:4` / `21:9`）。用在哪决定这个。**首帧图模式不用问**——2.5 强制跟随首帧图比例。
- **时长**：默认 5s（也是不加 `--allow-long` 时的上限）。
- **输入模式**：纯文字？带**首帧图**（图生视频，`--image`）？还是**多模态参考**（参考图/参考视频/参考音频，让新视频学参考的主体/运镜/风格）？两种模式互斥，先问清楚。
  - 参考视频/音频火山只收公网 URL；**本地文件（比如用户在群里发来的视频）脚本会自动上传 TOS 换预签名 URL**，前提是管理员配置了 TOS。参考图本地文件则自动 base64，不需要 TOS。
- **要不要声音**：2.5 支持原生音频，默认开。

分辨率(720p/1080p)、风格细节等有默认值，不必强问，但可顺带建议。

### ② 信息够了 → 先回显 + 确认，再生成（每次都要）
即使信息齐全，也**先把最终方案回显给用户、等一个明确确认**再调脚本：
- **润色后的最终 prompt**（视频提示词加镜头/运动/光线/节奏描述效果显著更好，主动帮用户润色并展示）
- **参数**：模型 / 比例 / 分辨率 / 时长 / 音频 / 是否图生
- **预估**：约 1~3 分钟，会产生火山方舟费用

例：「我打算这样生成 👉 prompt:『…』｜16:9 1080p 5s 带音频｜约 1-3 分钟、会计费。确认就发『可以』。」

### ③ 用户明确说"别问了/直接生成" → 跳过②的确认，直接跑
尊重显式指令。但①的"信息不足"仍要补齐（连画面都没有没法生成）。

## 核心命令

脚本位置（相对本 skill）：`scripts/gen_video.py`。API key 从环境变量 `ARK_API_KEY` 或 Luckagent 安装目录的 `.env` 自动读取，**无需 export**。

> ⚠️ 视频要跑 1~3 分钟。**用 Bash 跑这条命令时把 timeout 设到 ~360000ms（6 分钟）**，脚本内部会轮询直到完成。stdout 最后一行就是产物 mp4 路径。

### 文生视频（最常见）
```bash
python3 scripts/gen_video.py "<润色后的 prompt>" \
  --ratio 16:9 --resolution 1080p --duration 5 \
  --out <文件名>.mp4
```

### 图生视频（首帧控制模式）
```bash
python3 scripts/gen_video.py "<描述让首帧如何动起来>" \
  --image <首帧图路径或URL> \
  --ratio 9:16 --duration 5 \
  --out <文件名>.mp4
```

### 多模态参考模式（让新视频学参考的主体/运镜/风格）
与首帧模式**互斥**（别和 `--image` 混用）。三种参考可组合、可各传多次：
```bash
python3 scripts/gen_video.py "<prompt>" \
  --ref-image <参考图路径或URL> \        # reference_image：主体/风格一致（本地文件 OK，自动 base64）
  --ref-video "https://.../ref.mp4" \    # reference_video：运镜/动作/风格参考（★必须公网 URL）
  --ref-audio "https://.../ref.mp3" \    # reference_audio：本地文件自动传 TOS；2.5 起可单独用
  --out <文件名>.mp4
```
**参考输入规则**：
- **参考视频、参考音频**：火山 API 只收公网 URL。传 URL 直接用；**传本地文件时脚本自动上传到火山 TOS（`seedance-refs/` 前缀）并生成 2 小时预签名 URL 给 Ark 拉取，任务结束后自动删除**（`--keep-refs` 可保留）。需要管理员配好 TOS（`TOS_ACCESS_KEY` / `TOS_SECRET_KEY` / `TOS_BUCKET`）；没配时脚本在**提交任务之前**就报错，不会计费——照实告诉用户「参考本地视频/音频需要管理员先开通 TOS，或者给一个公网链接」。
- **参考图**：本地文件自动 base64，或传 URL。
- **数量上限（2.5）**：参考图 ≤30 张；参考视频 ≤10 段、参考音频 ≤10 段，**视频总时长 ≤30s、音频总时长 ≤30s**，单段 2~30s。
- **参考音频 2.5 起可单独使用**（2.0 必须搭配图/视频）。
- **不能直接上传含真人脸的参考图/视频**（会被输入审核拦截）。

### 2.5 任务类型的硬性限制（不遵守会在任务跑起来后报 `InvalidParameter.TaskTypeConstraint`）
模型按「素材 + 提示词意图」自动判定任务类型：
| 任务 | 触发 | 限制 |
|---|---|---|
| 首帧/首尾帧 | `--image` | `ratio` 只能 `adaptive`（脚本自动处理，传别的会被忽略） |
| 视频编辑 | 有 `--ref-video` + 提示词含「编辑/增加/删除/替换/改成」 | `ratio=adaptive` 且 **`--duration -1`**；原视频须 4~30s |
| 视频延长 | 有 `--ref-video` + 提示词含「向前/向后延长/延续/续写」 | `ratio=adaptive` |

带 `--ref-video` 时脚本默认 `ratio=adaptive`；做**视频编辑**记得加 `--duration -1`。

### 常用参数
| 参数 | 说明 | 默认 |
|---|---|---|
| `--ratio` | `16:9` / `9:16` / `1:1` / `4:3` / `3:4` / `21:9` / `adaptive` | 文生 `16:9`；首帧图 / 带参考视频 `adaptive` |
| `--resolution` | `480p` / `720p` / `1080p`（2.5 的 1080p 是 H.265 10bit） | `1080p` |
| `--duration` | 4~30 秒，或 `-1` 由模型自选；>5 需加 `--allow-long` | `5` |
| `--audio` / `--no-audio` | 原生音频开/关 | 开 |
| `--image` | 首帧图（本地文件自动转 base64） | 无（=文生视频） |
| `--model` | 覆盖模型 id | `doubao-seedance-2-5-260628` |
| `--out` | 输出 mp4 路径 | `seedance_<ts>.mp4` |

**时长上限**：默认 `--duration` 不能超 5s（防误刷烧钱）。用户明确要更长且在确认环节点头了，再加 `--allow-long`。

## 交付给用户

生成成功后，把产物 mp4 **复制到 system prompt 里给的发送目录**（「Output Files」一节的路径），桥接会自动把它当文件附件发到聊天（飞书里点开可下载/预览）。回复保持简洁，说明生成了什么、参数、时长即可。

## 未开通时怎么回

脚本报「视频生成未开通：未配置火山方舟 ARK_API_KEY」时，**不要尝试别的方式生成视频**，直接告诉用户：视频生成还没开通，需要管理员在管理台「系统配置 → 默认设置 → 视频生成」填写火山方舟 key（并在方舟控制台开通 Seedance 模型）。不要读取、打印或猜测任何 key。

## 排错
- **`HTTP 401/403`** → key 无效或没开通 Seedance 权限，请管理员去火山方舟控制台核对。
- **TOS 上传失败**（参考本地视频/音频时）→ 请管理员在管理台「视频生成」里点「测试 TOS」看具体原因（密钥 / 桶名 / 地域 / 权限）。
- **`HTTP 400` + 模型报错** → model id 变了（火山滚版本），用 `--model` 指定控制台里的当前 id。
- **轮询超时** → 服务器忙或时长/分辨率过高；重试或降参数。
- **轮询时网络抖动**（读超时等）→ 脚本自动重试，连续 5 次失败才退出，退出时会打印 task id。**任务已计费、服务端多半还在跑，别重新生成**，拿 task id 查询并下载即可。
- **任务报 `InvalidParameter.TaskTypeConstraint`** → 参数和 2.5 判定的任务类型冲突（见上方「2.5 任务类型的硬性限制」），常见是视频编辑没加 `--duration -1`。
- **1080p 成片播不了 / 没画面** → 2.5 的 1080p 是 H.265 10bit，少数播放器不支持；换 VLC/IINA/QuickTime，或改出 720p（8bit，兼容性更好）。
- **video_url 下载失败** → URL 24h 失效，必须生成后立刻下（脚本已自动处理，重试即重新生成）。
